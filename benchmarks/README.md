# Benchmark evidence

Real measurements are generated by `scripts/benchmark.sh` and written under `benchmarks/results/` (gitignored by default). The collector and simulator must be running. No latency numbers are claimed without this evidence. `poll_pXX_us` covers Modbus request/reply only, not end-to-end ingestion or operating-system scheduling guarantees.

For CI cross-language acceptance tests use `python3 scripts/integration.py --mode rust` after Cargo build.
