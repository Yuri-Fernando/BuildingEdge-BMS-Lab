Validade da medição

Uma amostra fica desatualizada após 3 segundos sem recebimento. A idade é medida no coletor, pelo relógio monotônico. Falha de API invalida a apresentação de todas as medições.

Retenção limitada

O histórico é global e mantido em memória. Ao atingir a capacidade configurada, a amostra mais antiga é removida. Reiniciar o coletor apaga os dados.

APPLICATION NETWORK

BMS1 · frame binário

31 bytes · big-endian · validação estrita no Rust.

magic4 BID2 Bseq8 Btimestamp8 Bdados9 B

Temperatura −50 a 125 °C, CO₂ até 10.000 ppm, umidade até 100%, potência até 50.000 W. Bits reservados são rejeitados.

Sequência monotônica por dispositivo. O protocolo atual não possui identificador de sessão: ao reiniciar um gateway com sequência zerada, reinicie também o coletor.
